# Changelog

## Naming update — 2026-10-18

- Renamed the project to **Clone Every Website 1:1 — Compiled Build to Components**, the repository to `clone-every-website-1-1` and the skill invocation to `$clone-every-website-1-1`.
- The experimental scope, review gate and fidelity limitations continue to apply; the title is not a guarantee for every website.

## 0.1.0 — initial public source distribution, 2026-10-18

- Packaged the existing Clone skill, deterministic engine, tests and synthetic fixtures for independent installation.
- Added Apache-2.0 licensing for original material and retained upstream licenses and attribution.
- Added installation, local demo, workflow, licensing and contribution documentation.
- Replaced the workspace-reused placeholder footage with a procedural eight-second video with a generator and provenance.
- Included explicit media choice, local runtime preflight, replay startup checks, conservative same-context media reuse and targeted source validation from the current Clone implementation.

Source and documentation are published in the [public repository](https://github.com/lucaschiaviniit-cloud/clone-every-website-1-1). Check [GitHub Actions](https://github.com/lucaschiaviniit-cloud/clone-every-website-1-1/actions/workflows/ci.yml) for CI results; these synthetic checks are not real-site benchmarks.

# Roadmap

## Included in this release

Local capture/replay, explicit original-versus-placeholder media selection, runtime preflight, startup checks, hash-bound approval, source-workspace preparation, inventory/dossiers, source comparison and delivery tools.

## Next validation work

- Test clean installation by external users and document supported platforms.
- Publish authorized real-site examples with reproducible interaction scenarios.
- Measure operator time, elapsed time, agent costs, storage, failures and final fidelity against a defined alternative workflow.
- Improve failures demonstrated by those observations.

## Separate product directions

Fusion, original component packs, template products and enterprise services may build on shared infrastructure. Their mention here does not make them part of the released Clone skill or establish availability or delivery dates. The engine retains its existing optional Fusion interface; no Fusion skill is bundled.
